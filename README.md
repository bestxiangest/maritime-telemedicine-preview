# 海上远程医疗网站视觉原型

静态交互原型，使用 HTML、CSS 和原生 JavaScript，无需安装前端依赖。

## 预览

在本目录启动静态服务器，或直接打开 `index.html`。建议通过本地 HTTP 服务预览。

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory "."
```

页面入口：

- `index.html`：品牌首页、滚动影像与系统介绍
- `products.html`：船端工作站、可切换的平台界面、部署流程与常见问题
- `solutions.html?scene=merchant`：远洋商船方案
- `solutions.html?scene=cruise`：邮轮客运方案
- `solutions.html?scene=offshore`：海上作业平台方案

场景切换保留独立地址，支持刷新、浏览器前进和后退。

## 可体验的交互

- 桌面首页随滚动逐帧推进与回退，停止滚动即停留在对应画面
- 首页标题与第二段文案随滚动切换
- 手机端使用竖版静态首帧，不请求桌面图片序列
- 系统协同节点与下一环节切换
- 船端设备与软件界面切换
- 医疗设备整体外观与采集细节切换
- 医疗服务内容展开
- 图文协同流程演示、上一步/下一步与可暂停的自动播放
- 场景图文弹窗及完整方案入口
- 设备图片灯箱，支持左右方向键切换
- 两步预约弹窗、场景预选、表单校验与演示结果
- 产品中心平台栏目切换及键盘导航
- 页面分段入场、滚动阅读进度、章节导航与快捷咨询
- 手机端导航与响应式页面

弹窗支持 Escape、关闭按钮和点击遮罩关闭，关闭后焦点返回入口。表单返回上一步时保留当前填写内容；关闭或完成演示时清空。内容不会发送或保存。自动演示在关闭弹窗、页面进入后台或开启减少动态效果时停止。

设备外观和软件界面为概念示意，图像来源见 `ASSETS.md`。当前为前端交互原型，预约和平台界面尚未连接后台。

`ui.js` 管理公共导航、弹窗与入场效果；`app.js` 管理首页节点和产品切换；`subpages.js` 管理产品中心与场景方案；`experience.css` 提供子页面及弹窗样式。浏览器选择减少动态效果时，保留静态内容并跳过切换动画。

## 滚动影像

`hero-sequence.js` 使用 CSS sticky、原生滚动事件和 Canvas。桌面视口宽度至少 961px、高度至少 650px 时启用；选择减少动态效果或启用浏览器省流量偏好时保持静态首帧。

原片为 10 秒、720p、24 fps，提取为 240 张 WebP，合计约 22.8 MB。序列采用并发上限为 4 的后台预取，目标帧优先；保留压缩数据以便回退，解码图像缓存最多 18 张。快速滚动时绘制最新目标帧，加载期间保留上一张有效画面。离开影像区域时停止预取并释放解码缓存，手机端不加载序列清单。

仓库包含网页和优化后的展示素材，原始图片、视频及本地处理脚本保留在本机。图片序列需要通过 HTTP 服务加载，直接双击 HTML 时保留静态海报。

## 静态发布

GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 用于直接提供静态文件。后续推送到 `main` 的修改会自动更新预览网站，无需单独安装构建依赖。
